# NMD Sales Tracker

Sales dashboard for Nasik Metaldust, Plant P-65 (NMD - 65): daily, monthly and yearly sales against ABP value and quantity targets and last year.

- Website: GitHub Pages (this repository, `index.html`).
- Logins, targets and sales data: Firebase (Authentication + Firestore). Settings in `firebase-config.js`.
- This repository contains **no sales data**. Data is loaded after sign-in from Firebase.
- Roles: **Admin** (upload data, targets, logins) and **Viewer** (read only).

Do not upload backup files (`NMD_Sales_data_backup_*.json`) to this repository.
